# Travel Trip

A multi-step trip booking app built with React.

## Features

- Five steps: Your Details, Date Selection, Guests, Travel Assistance and Confirmation
- Step progress bar showing the active and completed steps
- Form validation with error messages for each step
- Entered details are kept when moving between steps
- Cancel and Book New Trip reset the form

## Tech Stack

React.js (functional components, useState), JavaScript, HTML, CSS, Vite

## Run Locally

```
npm install
npm run dev
```
